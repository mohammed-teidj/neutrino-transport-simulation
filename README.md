# Simulation of the Transport Chain of High-Energy Astrophysical Neutrinos

## 📌 Overview
This repository contains the numerical simulation and data analysis framework for a Master's research project on neutrino transport chains. The project focuses on modeling physical processes, analyzing particle transport, and visualizing scientific outputs using Python.

> **Note:** The original Master's thesis and documentation were written in French (*Mémoire de Master en Physique de la Matière et de Rayonnement*).

## 🛠️ Tools & Technologies
- **Programming Language:** Python 3.x
- **Scientific Libraries:** NumPy, SciPy, Matplotlib, Pandas
- **Environment:** VMware Workstation 17 (Linux Environment), Windows PowerShell
